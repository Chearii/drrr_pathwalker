[DISCLAIMER]

This system uses elements of decompiled (reverse engineered) code from Mario Kart DS, reworked to both use the Lua language,
and to be reliant on Ring Racers' internal systems, and not any internal Nintendo DS systems. All potentailly reliant systems
have been, to the best of my ability (and extent of my knowledge), reworked to use Ring Racers systems, or use unique ways
of getting the same result (clean-room code). *No assets from Mario Kart DS have been included in this addon, nor will they be.*
